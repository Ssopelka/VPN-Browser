# VPN Terminal

Расширение для Яндекс Браузера, Chrome, Edge и других браузеров на Chromium. Направляет через VPN весь трафик или только заблокированные в РФ ресурсы.

Протоколы: vless (Reality, Vision), vmess, trojan, shadowsocks, hysteria, hysteria2, tuic, anytls, socks5, http(s)-прокси.

## Установка

1. Скачайте установщик из [Releases](../../releases/latest): `VPN-Terminal-Setup-windows-x64.exe` (для ARM: `windows-arm64`).
2. Запустите файл. Он установит хост в `%LOCALAPPDATA%\VPN Terminal`, зарегистрирует его в браузерах и откроет папку с расширением. Права администратора не нужны.
3. Откройте `browser://extensions`, включите режим разработчика, нажмите «Загрузить распакованное» и выберите открывшуюся папку `extension`.
4. В настройках расширения вставьте ссылку-подписку или ключ и нажмите кнопку питания.

Обновление: хост обновляется сам (Настройки → Обновление) или запуском нового установщика.
Удаление: `VPN-Terminal-Setup-windows-x64.exe uninstall`, затем удалите расширение в браузере.

Установщик не подписан, поэтому SmartScreen может показать предупреждение. Контрольные суммы лежат в `SHA256SUMS.txt` рядом с файлами релиза.

## Возможности

- Режимы «весь трафик» и «блокировки РФ» с автообновляемыми списками, свои исключения и домены «всегда через VPN».
- Выбор сервера, если в подписке их несколько.
- Правило для текущего сайта: «Авто», «VPN» или «Напрямую» одним нажатием.
- Автоподключение при запуске браузера.
- Kill-switch: при обрыве VPN трафик блокируется, а не уходит напрямую. Расширение переподключается само.
- Защита от утечки IP через WebRTC.
- Статистика трафика, график скорости, замер скорости.
- Журнал событий с экспортом в файл. Ключи, ссылки и адреса серверов в журнал не попадают.
- Список серверов подписки с флагами стран.
- Экспорт и импорт настроек в файл.
- Автоматическое обновление хоста и расширения из релизов GitHub: файл скачивается с `github.com/Ssopelka/VPN-Browser/releases`, сверяется с `SHA256SUMS.txt` и заменяет установленный. Ручной запуск: `vpn-terminal update`.

## Архитектура

Расширение задаёт PAC-скрипт, который направляет запросы на локальный HTTP-прокси хоста. Хост (`vpn-terminal`) запускается браузером через native messaging и содержит ядро [sing-box](https://github.com/SagerNet/sing-box). Порт и пароль локального прокси создаются заново при каждом подключении, слушает он только `127.0.0.1`.

Подробнее о защите: [SECURITY.md](SECURITY.md). Подпись установщика и публикация в Chrome Web Store: [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Сборка

```
go test -tags with_utls ./host
GOOS=windows go build -trimpath -tags with_utls -ldflags "-s -w -H=windowsgui" -o VPN-Terminal-Setup.exe ./host
```

Нужен Go 1.25 или новее. Тег `with_utls` обязателен для Reality. CI собирает установщики и публикует релиз при каждом push в `main`.
