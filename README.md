# VPN Terminal

Расширение для Яндекс Браузера, Chrome, Edge и других браузеров на Chromium: весь трафик или только заблокированные в РФ ресурсы идут через VPN.
Протоколы: vless (Reality, Vision), vmess, trojan, shadowsocks, hysteria / hysteria2, tuic, anytls, socks5, http(s)-прокси.

## Установка (один файл)

1. Скачайте установщик из [Releases](../../releases/latest): `VPN-Terminal-Setup-windows-x64.exe` (на ARM — `…arm64.exe`).
2. Запустите его двойным щелчком. Он:
   - кладёт ядро в `%LOCALAPPDATA%\VPN Terminal` (ядро sing-box вшито в файл, из интернета ничего не скачивается);
   - регистрирует хост для Яндекс Браузера, Chrome, Edge, Brave (права администратора не нужны);
   - распаковывает расширение и открывает его папку.
3. В браузере откройте `browser://extensions` (`chrome://extensions`), включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите открывшуюся папку `extension`.
4. В «Настройках» вставьте ссылку-подписку или ключ и нажмите кнопку питания.

Обновление: запустите новую версию установщика, затем «Обновить» у расширения.
Удаление: `VPN-Terminal-Setup-….exe uninstall` (из командной строки), затем удалите расширение в браузере.

> Файл не подписан, поэтому SmartScreen и антивирусы могут показать предупреждение. Исходники и сборка открыты: см. `.github/workflows/build.yml`. Проверить файл можно по `SHA256SUMS.txt` из релиза.

## Как это работает

```
расширение (PAC-скрипт) ──HTTP-прокси 127.0.0.1:<случайный порт> + логин/пароль──▶ vpn-terminal.exe (хост + ядро sing-box)
                              ▲ native messaging (stdin/stdout)                              │
                              └────────── команды start/stop, статистика ◀─────────────────┘ ──▶ VPN-сервер
```

- Браузер сам запускает `vpn-terminal.exe` через native messaging, когда расширение подключается, и гасит его при отключении.
- Порт и пароль локального прокси генерируются заново при каждом подключении, прокси слушает только `127.0.0.1`.
- Статистика читается из памяти ядра, никакого HTTP-API на локальном порту нет.

## Режимы и защита

- **Весь трафик** или **блокировки РФ** (списки доменов обновляются автоматически, свои исключения и «всегда через VPN» настраиваются).
- **Автоподключение** при запуске браузера. Пока VPN поднимается, при включённом kill-switch запросы блокируются, а не уходят напрямую.
- **Kill-switch**: если VPN упал, трафик не уходит напрямую; расширение само пытается переподключиться (2 → 5 → 15 с).
- Защита от утечки IP через WebRTC, локальная сеть напрямую.

Подробности проверки безопасности — в [SECURITY.md](SECURITY.md).

## Сборка из исходников

```
go test -tags with_utls ./host
GOOS=windows go build -trimpath -tags with_utls -ldflags "-s -w -H=windowsgui" -o VPN-Terminal-Setup.exe ./host
```

Нужен Go 1.25+. Тег `with_utls` обязателен для Reality и uTLS-отпечатка. Каждый push в `main` собирает установщики и публикует релиз в [Releases](../../releases).
