# VPN Terminal — установка

1. Дважды щёлкните **`install.bat`**.
2. Откройте `browser://extensions` и включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `extension`.
4. В «Настройках» вставьте ссылку или ключ, нажмите кнопку питания.

Папку переместили — запустите `install.bat` ещё раз.

**Удаление:** запустите `uninstall.bat`, затем удалите расширение в `browser://extensions`.
