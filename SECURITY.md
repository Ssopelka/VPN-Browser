## Остаточные риски

- **История git.** Старые ключи сервера доступны через историю. Нужна ротация ключей.
- **`<all_urls>` и `webRequest`.** Нужны для проксирования и учёта трафика в режиме прямого прокси; расширение не читает содержимое страниц.
- **Подписка и ключ** хранятся в `chrome.storage.local` открытым текстом (как у большинства расширений); доступны тем, у кого есть доступ к профилю браузера.
- **Подписка по `http://`** скачивается без шифрования, используйте `https://`.
- **Внешние запросы расширения:** `api.ipify.org` (показ IP), `speed.cloudflare.com` (замер скорости), `cp.cloudflare.com` (проверка VPN хостом), GitHub raw и antifilter (списки блокировок).
- **Неподписанный exe**: SmartScreen и антивирусы могут ругаться.

## Тесты

`go test -tags with_utls ./host` — разбор ссылок всех протоколов, кадры native messaging, сквозной тест: встроенный клиент ↔ in-process сервер Shadowsocks ↔ веб-сервер, проверка, что локальный прокси отклоняет запросы без логина и с неверным паролем, что в конфиге нет clash_api и 0.0.0.0.

Сквозной тест в реальном Chromium (Playwright): подключение через хост, трафик идёт через туннель, при падении VPN-сервера сайт не открывается напрямую, переподключение после падения хоста, автоподключение при старте браузера, ошибка при некорректной ссылке.
